# Evaluation

## Representative task

Task: Route a request to add a Python service endpoint, choose a backend foundation, and review its service boundary.

Expected: Select the backend router, then route to Python plus core/API or service-architecture guidance as needed.

Failure condition: Load Go, Node.js, and all backend children without a reason.

Validation: Confirm the route follows the task's language and outcome.

## Boundary task

Task: Design a data warehouse transformation with no service API.

Expected: Route to data skills rather than backend.

Failure condition: Force every data task through service engineering.

Validation: Confirm the selected path is data.
