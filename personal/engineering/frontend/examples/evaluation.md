# Evaluation

## Representative task

Task: Route a request to build a small personal web interface backed by an existing API.

Expected: Select lightweight-web and avoid loading backend or infrastructure skills unless the request crosses those boundaries.

Failure condition: Start a large frontend platform for a small interface without a requirement.

Validation: Confirm the route names the minimal UI workflow.

## Boundary task

Task: Implement a database migration for the API backend.

Expected: Route to backend/data-engineering guidance, not frontend.

Failure condition: Treat a UI consumer as the owner of persistence changes.

Validation: Confirm the selected skill matches the migration boundary.
