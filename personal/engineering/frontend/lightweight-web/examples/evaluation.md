# Evaluation

## Representative task

Task: Build a small responsive page with clear states, accessible controls, and a minimal build setup.

Expected: Prefer simple maintainable structure, explicit loading/error/empty states, and only necessary tooling.

Failure condition: Add framework or dependency complexity without a user or maintenance need.

Validation: Inspect the page states, run the build, and perform a basic accessibility review.

## Boundary task

Task: Design a multi-team frontend platform with shared packages and independent deployment.

Expected: Escalate to architecture review and scope analysis rather than treating it as a lightweight page.

Failure condition: Apply small-project constraints to a clearly platform-scale requirement.

Validation: Confirm the architecture boundary is explicitly reviewed.
