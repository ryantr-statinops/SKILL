# Evaluation

## Representative task

Task: Route a request to diagnose a containerized service that cannot reach a dependency.

Expected: Select Docker and networking, with Linux support only if host behavior is involved.

Failure condition: Load all infrastructure skills without narrowing the failure boundary.

Validation: Confirm the route follows the observed layer and dependency path.

## Boundary task

Task: Define a product MVP for a new personal idea.

Expected: Route to product/project-scoping rather than infrastructure.

Failure condition: Discuss deployment before the product outcome is defined.

Validation: Confirm infrastructure is deferred until a concrete delivery need exists.
