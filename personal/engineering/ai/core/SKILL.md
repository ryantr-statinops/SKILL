# AI engineering foundations

This is an initial scaffold, not a complete AI engineering skill.

## Current foundation

- Define the user outcome before choosing a model or agent pattern.
- Separate model reasoning, agent orchestration, tools/MCP, memory, and evaluation.
- Keep context and tool permissions minimal.
- Evaluate behavior with representative and boundary tasks.

Detailed workflows for agent engineering, MCP integration, prompt/context
design, and agent evaluation will be added later.
