# Evaluation

## Representative task

Task: Route a request to build a Node.js API backed by a scheduled data pipeline.

Expected: Select backend/nodejs and data/pipelines, loading only the relevant foundation guidance.

Failure condition: Load all engineering domains or select an unrelated frontend workflow.

Validation: Confirm the route names the primary implementation skill and supporting skill.

## Boundary task

Task: Decide whether a quantitative signal is statistically credible.

Expected: Route to quant research or backtesting, not the engineering router.

Failure condition: Treat a research-validity question as an implementation task.

Validation: Confirm the selected route is under personal/quant.
