# Evaluation

## Representative task

Task: Define a personal project before implementation when users, constraints, and success criteria are still unclear.

Expected: State outcome, user, constraints, boundaries, risks, and a measurable definition of done.

Failure condition: Jump directly to a technology or task list without clarifying the problem.

Validation: Review the scope brief and confirm each constraint is actionable.

## Boundary task

Task: Add a narrowly specified function to an existing project.

Expected: Use the project workflow and implementation skill; do not reopen project scope unless a conflict appears.

Failure condition: Delay a bounded change with a full product discovery exercise.

Validation: Confirm the existing scope remains intact.
