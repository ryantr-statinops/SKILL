# Evaluation

## Representative task

Task: Create a maintainable mathematical note with equations, references, and reproducible compilation.

Expected: Define document structure, isolate reusable commands, and validate the generated output.

Failure condition: Produce a one-off document with hidden manual steps or broken references.

Validation: Compile the document and inspect references, warnings, and output structure.

## Boundary task

Task: Explain a probability theorem without writing or formatting a document.

Expected: Use the probability education workflow; activate LaTeX only if a document artifact is requested.

Failure condition: Add formatting work that does not serve the request.

Validation: Confirm the response is explanation-first.
