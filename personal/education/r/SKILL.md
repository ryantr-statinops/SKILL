# R foundations

## When to use
Use when learning R or applying it to an educational analysis.

## Personal principles
Explain the statistical idea before the syntax and keep analysis reproducible.

## Workflow
State the question, inspect data, demonstrate the smallest R operation, interpret output, and verify assumptions.

## Decision rules
Do not hide statistical reasoning behind a one-line package call.

## Constraints
Do not claim causality from descriptive output alone.

## Failure modes
If data or statistical assumptions are unclear, teach the limitation first.

## Expected output
Provide concept, code, interpretation, and reproducible next step.

## Validation
The learner can explain the result and rerun the example.
