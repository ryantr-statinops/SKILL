# Evaluation

## Representative task

Task: Explain the probability of an event involving dependent random variables and verify it with a small simulation.

Expected: Define the sample space, assumptions, dependence, derivation, and simulation comparison.

Failure condition: Apply an independence formula without checking assumptions.

Validation: Compare the derivation with a reproducible simulation and state approximation limits.

## Boundary task

Task: Interpret a confidence interval from an experiment.

Expected: Route to statistics unless the task explicitly requires probability foundations.

Failure condition: Explain the interval as a probability statement about a fixed parameter.

Validation: Confirm statistical interpretation is preserved.
