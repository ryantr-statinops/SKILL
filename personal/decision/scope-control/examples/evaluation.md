# Evaluation

## Representative task

Task: A personal project has accumulated analytics, mobile, automation, and collaboration ideas before its first useful release.

Expected: Separate current commitment, experiment, and later ideas; preserve one measurable next outcome.

Failure condition: Add every attractive idea to the immediate implementation scope.

Validation: Review the resulting in-scope/out-of-scope list and next milestone.

## Boundary task

Task: A production incident requires an urgent reliability fix.

Expected: Treat the fix as an operational priority, not as optional scope creep.

Failure condition: Defer the incident because it was not in the original MVP list.

Validation: Confirm the incident has an explicit owner and verification step.
