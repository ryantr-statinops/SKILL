# Evaluation

## Representative task

Task: Start a new personal software repository with minimal structure, conventions, documentation, and validation.

Expected: Establish a runnable baseline, clear README, ignored local files, and the first useful check.

Failure condition: Create a large framework before identifying the first runnable outcome.

Validation: Clone or run the project from a clean state and execute the documented check.

## Boundary task

Task: Add a feature to an existing repository with conventions already established.

Expected: Use the repository onboarding and task-planning workflow rather than reinitializing the project.

Failure condition: Overwrite existing project structure or conventions.

Validation: Confirm no initialization files were recreated unnecessarily.
