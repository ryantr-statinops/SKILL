# Evaluation

## Representative task

Task: Research an unfamiliar technology to decide whether it fits a personal project.

Expected: Define the question, collect relevant evidence, compare alternatives, and produce a bounded recommendation with uncertainty.

Failure condition: Summarize sources without connecting evidence to a decision.

Validation: Review source quality, comparison criteria, conclusion, and unresolved questions.

## Boundary task

Task: Implement a known change from an already-approved design.

Expected: Use the implementation skill and research only newly discovered unknowns.

Failure condition: Expand a settled task into open-ended browsing.

Validation: Confirm research effort is proportional to uncertainty.
