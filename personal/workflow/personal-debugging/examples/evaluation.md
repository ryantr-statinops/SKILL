# Evaluation

## Representative task

Task: Investigate a failing test in a personal project from reproduction through verified fix.

Expected: Preserve evidence, isolate the smallest cause, make a focused change, and rerun relevant checks.

Failure condition: Patch symptoms, delete the failing test, or change unrelated code without evidence.

Validation: Reproduce before the fix and pass the targeted plus regression checks after it.

## Boundary task

Task: Design a new feature with no failure or defect to investigate.

Expected: Route to planning or product workflow rather than debugging.

Failure condition: Invent a bug investigation to avoid defining the feature.

Validation: Confirm the output is a scoped plan.
