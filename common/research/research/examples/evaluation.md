# Evaluation

## Representative task
Task: Research a current technical question using primary sources and separate facts from inference.

Expected: traceable claims, caveats, and a labeled conclusion.

Failure condition: Present inference or outdated information as established fact.

Validation: Check source links, dates, claim scope, and inference labels.

## Boundary task
Task: Answer a stable fact already provided by authoritative local documentation.

Expected: use the supplied source without unnecessary broad research.

Failure condition: Browse broadly when authoritative local evidence already answers the task.

Validation: Confirm the answer is grounded in the supplied documentation.
