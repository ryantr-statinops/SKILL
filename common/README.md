# Common Skills

Portable workflows for engineering, research, data, security, delivery, and
agent operations. Use these skills across repositories; keep project-specific
preferences in `personal/` and skill-system procedures in `meta/`.

| Design or run tests | [testing](engineering/testing/SKILL.md) |
