# Evaluation

## Representative task
Document a new command for a user who needs prerequisites, usage, output, and verification.

Expected: runnable, audience-appropriate instructions with checked links and commands.

Failure condition: Document commands or behavior that were not verified.

Validation: Follow the instructions from a clean context and check links.

## Boundary task
Document behavior that has not been verified in source or execution.

Expected: verify it or label the statement as uncertain.

Failure condition: Present an unverified claim as repository behavior.

Validation: Trace the claim to source or an executed check.
