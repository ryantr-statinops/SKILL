## Representative task

Task: Choose a database for a new service by researching workload fit, consistency, operations, cost, compatibility, and migration risk.

Expected: Use research-decision to define the decision and criteria, gather high-trust evidence, compare alternatives, recommend an option, and record uncertainty in a cited artifact.

Failure condition: Produce an uncited feature list, hide conflicting evidence, or recommend an option before criteria are defined.

Validation: Confirm the report distinguishes sourced facts from inferences and includes source links, trade-offs, confidence, and follow-up.

## Boundary task

Task: Implement a previously selected database schema and add tests.

Expected: Route to feature-delivery or the relevant engineering skills rather than research-decision.

Failure condition: Start new research despite a settled decision and an implementation request.

Validation: Confirm the research workflow is rejected and an implementation workflow is recommended.
