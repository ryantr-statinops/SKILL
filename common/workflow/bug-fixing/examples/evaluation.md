## Representative task

Task: Diagnose a failing API regression test, isolate the root cause, add a regression test, fix the behavior, and report verification.

Expected: Use bug-fixing to reproduce, minimize, form evidence-based hypotheses, fix the root cause, regression-test, review, and hand off the result.

Failure condition: Guess at the cause, skip reproduction or regression evidence, or refactor unrelated code.

Validation: Confirm the response reports reproduction status, evidence, root cause, fix, regression test, checks, and unresolved risks.

## Boundary task

Task: Build a new export feature with a specification, tests, implementation, and review.

Expected: Route to feature-delivery rather than bug-fixing.

Failure condition: Treat planned feature work as a defect diagnosis.

Validation: Confirm the bug workflow is rejected and the feature workflow is recommended.
