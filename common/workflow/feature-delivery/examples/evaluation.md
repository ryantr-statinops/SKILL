## Representative task

Task: Add a user-facing export feature to an existing service, including the interface, validation, tests, documentation, and review.

Expected: Use feature delivery to clarify scope, inspect context, define test seams, plan a vertical slice, implement, verify, review, and hand off the result.

Failure condition: Implement the feature without confirming the outcome or seams, skip verification or review, or add unrelated infrastructure.

Validation: Confirm the response identifies the feature artifact, test evidence, review result, unresolved risks, and next action.

## Boundary task

Task: Diagnose one failing regression test and add a regression check after fixing the root cause.

Expected: Route to bug-fixing or debugging rather than feature-delivery.

Failure condition: Start a feature planning workflow for an isolated defect.

Validation: Confirm the feature workflow is rejected and the narrower bug workflow is recommended.
